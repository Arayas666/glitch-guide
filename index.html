Как запустить GLITCH

Скачайте лоадер, запустите его перед игрой и откройте меню клавишей DEL.

Windows 10 / 11
Процессор: Intel / AMD · Видеокарта: NVIDIA / AMD

Конкретные сборки Windows, модели оборудования и минимум RAM/диска уточняйте в поддержке.

Запуск за три шага

  1. Скачайте лоадер GLITCH

    Используйте официальную страницу загрузки.

    Скачать лоадер ↗

  2. Сначала лоадер, затем RUST

    Запустите лоадер GLITCH и выполните действия, указанные в его окне. После этого запустите RUST.

  3. Откройте меню: DEL

    В активном окне игры нажмите Delete. Язык RU / EN выбирается внизу боковой панели меню.

Если возник вопрос

Меню не открывается

Проверьте, что лоадер запущен перед RUST, а окно игры активно. Нажмите DEL (Delete). Если меню не появилось, отправьте поддержке текст ошибки или скриншот.

Доступны только визуальные функции

Проверьте Safe Mode в разделе Other. Сообщение «Only Visuals are available» означает, что в этом режиме доступны только визуальные функции.

Что отправить в поддержку

Опишите, на каком шаге возникла проблема. Приложите текст ошибки или скриншот, версию Windows и модели CPU/GPU. Не отправляйте полный лицензионный ключ.

Get started with GLITCH

Download the loader, run it before the game, then press DEL to open the menu.

Windows 10 / 11
Processor: Intel / AMD · Graphics: NVIDIA / AMD

Contact support for specific Windows builds, hardware models and minimum RAM/storage requirements.

Three steps to get started

  1. Download the GLITCH loader

    Use the official download page.

    Download loader ↗

  2. Loader first, then RUST

    Run the GLITCH loader and follow its on-screen steps. Then launch RUST.

  3. Open the menu: DEL

    With the game window active, press Delete. Select RU / EN at the bottom of the menu sidebar.

Common questions

The menu does not open

Make sure you launched the loader before RUST and the game window has focus. Press DEL (Delete). If the menu does not appear, send support the error text or a screenshot.

Only visual features are available

Check Safe Mode under Other. The message “Only Visuals are available” means this mode is limited to visual features.

What to send to support

Describe the step where the issue occurred. Include the error text or a screenshot, your Windows version and CPU/GPU models. Do not send your full license key.
