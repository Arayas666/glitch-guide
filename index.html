01 Riot Vanguard — удаление

  1. Закройте игры Riot и Riot Client, в том числе значок клиента рядом с часами.
  2. В поиске «Пуск» найдите «Установка и удаление программ». В списке приложений выберите Riot Vanguard → Удалить и завершите удаление.
  3. Выполните Пуск → Питание → Перезагрузка.
  4. Проверьте, что Riot Vanguard больше нет в списке установленных приложений. Если удаление завершилось ошибкой, передайте её текст поддержке.

Игры Riot, которым нужен Vanguard, потребуют его повторной установки. Запуск Riot Client или такой игры может установить его заново.

Порядок удаления: справка Riot Games ↗

02 FACEIT Anti-Cheat — удалить или отключить

Предпочтительный вариант: удалить

  1. Закройте игру и FACEIT Anti-Cheat.
  2. Откройте «Установка и удаление программ» через поиск «Пуск». Найдите именно FACEIT Anti-Cheat, выберите Удалить и пройдите шаги деинсталлятора.
  3. Перезагрузите компьютер и проверьте список приложений. Удаление обычного клиента FACEIT само по себе не подтверждает удаление Anti-Cheat.

Если оставляете Anti-Cheat установленным

В трее рядом с часами откройте меню значка FACEIT Anti-Cheat и выберите Disable driver. Закрытие окна приложения не равно отключению драйвера. После перезагрузки драйвер снова включается — отключайте его после последней перезагрузки перед GLITCH.

Штатное отключение драйвера: справка FACEIT ↗

Отключение через CMD и проверка результата

Этот вариант подходит только для установки, в которой драйвер зарегистрирован под именем FACEIT и допускает остановку. Имя и возможность остановки могут отличаться между версиями.

  1. В «Пуск» введите cmd, выберите «Запуск от имени администратора» и подтвердите запрос Windows. Закройте FACEIT Anti-Cheat и игру.
  2. Выполните две команды по очереди — они только показывают состояние и конфигурацию: 
    sc.exe query FACEIT
sc.exe qc FACEIT
  3. Продолжайте, только если это KERNEL_DRIVER, а путь BINARY_PATH_NAME относится к установленному FACEIT Anti-Cheat. Если получили 1060, это означает, что служба с таким именем не найдена; это не доказывает отсутствие Anti-Cheat. Используйте удаление или пункт Disable driver выше.
  4. Для подтверждённого драйвера выполните: 
    sc.exe stop FACEIT
sc.exe query FACEIT
  5. В строке STATE должно быть STOPPED. При STOP_PENDING подождите и повторите только sc.exe query FACEIT. При ошибке, отказе в доступе или RUNNING отключение не подтверждено — используйте штатное отключение либо удаление.

Команда stop не удаляет Anti-Cheat и не меняет автозапуск. После перезагрузки снова проверьте драйвер. Проверка одного имени службы не подтверждает совместимость всей системы.

Синтаксис и ограничения: Microsoft: sc query ↗ · Microsoft: sc stop ↗

03 HVCI — выключить «Целостность памяти»

HVCI — это параметр «Целостность памяти» / Memory integrity в безопасности Windows. Откройте его по пути для своей ОС:

Windows 11

Параметры → Конфиденциальность и безопасность → Безопасность Windows → Безопасность устройства → Сведения об изоляции ядра.

Windows 10

Параметры → Обновление и безопасность → Безопасность Windows → Безопасность устройства → Сведения об изоляции ядра.

  1. Установите «Целостность памяти» → Выкл.
  2. Перезагрузите ПК. Снова откройте этот экран и убедитесь, что осталось «Выкл.».

Отключение HVCI снижает защиту Windows. Если параметр недоступен или управляется организацией, обратитесь к администратору ПК или в поддержку GLITCH.

Путь и перезагрузка: справка Microsoft ↗

04 VBS — проверить отдельно

Обязательное отключение VBS для GLITCH пока не подтверждено. Выключенный HVCI не означает, что VBS целиком выключен. VBS, HVCI и Hyper-V — разные понятия; проверяйте именно нужный параметр.

  1. Нажмите Win + R, введите msinfo32 и нажмите Enter.
  2. В «Сведениях о системе» найдите «Безопасность на основе виртуализации» / Virtualization-based security.
  3. Скопируйте значение целиком. Если GLITCH не запускается, сообщите его поддержке вместе с состоянием HVCI. Само по себе это значение не доказывает причину ошибки.

Эта проверка не требует отключать Hyper-V или виртуализацию процессора в BIOS/UEFI. Изменение этих параметров согласуйте с поддержкой под вашу конфигурацию.

HVCI, VBS и проверка состояния: Microsoft Learn ↗

Проверка перед запуском GLITCH

  • Riot Vanguard удалён, если был установлен.
  • HVCI выключен; после изменения и удаления компонентов выполнена перезагрузка.
  • FACEIT Anti-Cheat удалён либо его драйвер отключён после последней перезагрузки.
  • Если были ошибки при подготовке, их текст сохранён для поддержки.
Перейти к запуску: лоадер → RUST → DEL ↓

Запуск

Подготовка Windows → Перезагрузка → Лоадер GLITCH → RUST → DEL

Перед запуском пройдите проверку подготовки. Если FACEIT остался установленным, отключите его драйвер после перезагрузки.

  1. Скачайте официальный лоадер

    Откройте страницу загрузки GLITCH по кнопке ниже. Используйте актуальный файл, который выдаёт эта страница.

    Скачать лоадер ↗

    glitch.orion-security.pro/launcher

  2. Запустите лоадер GLITCH

    Выполните действия, указанные в его окне. Названия кнопок и вид экрана зависят от версии лоадера. Если возникает ошибка, сохраните её текст и обратитесь в поддержку.

  3. Затем запустите RUST

    Соблюдайте порядок: сначала лоадер GLITCH, после него игра. Если RUST уже был открыт, закройте игру и повторите запуск в этом порядке.

  4. Откройте меню клавишей DEL

    Переключитесь в окно игры и нажмите Delete. На компактной клавиатуре расположение Delete и необходимость Fn зависят от модели клавиатуры.

  5. Выберите язык и настройте отображение

    RU / EN находится внизу боковой панели. Начните с масштаба и размера шрифта, затем переходите к нужным разделам.

Первая настройка

Язык и читаемость

Выберите RU или EN. Interface Scale меняет масштаб меню, Font Size — размер текста. Если подписи неудобно читать, сначала настройте эти параметры.

Внешний вид

Accent Color задаёт акцентный цвет, Theme — тему, Menu Corners — форму углов. Animations Speed и Animation Mode относятся к анимациям интерфейса.

Как менять параметры

Переключатель включает или выключает функцию. Ползунок меняет числовое значение, список — вариант, цветовой образец — цвет. Связанные настройки могут зависеть от основного переключателя раздела.

Настройка визуализации

Начните с нужных типов объектов и дистанции отображения. Добавляйте подписи и дополнительные слои по одному, чтобы экран оставался читаемым. Preview позволяет оценить отображение там, где такой предпросмотр есть.

Производительность

В Other находятся FPS Limit, FPS Limit Value и ESP Delay. Меняйте один параметр за раз и сравнивайте результат. Если после изменения стало хуже, верните предыдущее значение.

Safe Mode

В Other режим Safe Mode сопровождается сообщением «Only Visuals are available»: в этом режиме доступны только визуальные функции. Его название не означает гарантию отсутствия блокировки.

Решение проблем

Загрузка или подключение не завершается

Сохраните текст сообщения и время, убедитесь, что интернет работает в обычных сервисах, затем попробуйте ещё раз позднее. Если проблема остаётся, передайте собранные данные в официальный канал поддержки GLITCH.

Меню не видно или клавиша не срабатывает

Запускайте лоадер GLITCH перед RUST. В активном окне игры нажмите DEL (Delete). Если меню не появилось, передайте @cortez_1337 версию продукта, текст ошибки и этап, на котором остановился запуск.

Интерфейс мелкий, большой или отображается со смещением

Сначала проверьте доступные настройки интерфейса внутри GLITCH, например масштаб или размер шрифта. Если это не помогает, приложите разрешение экрана, масштаб Windows и скриншот — поддержке нужны эти данные для проверки.

После настройки изменилось поведение

Верните последний изменённый параметр к прежнему значению через меню. Проверяйте по одному изменению за раз. Если проблема сохраняется, приложите снимок соответствующего раздела и опишите ожидаемое поведение.

Что означает Safe Mode?

На предоставленном скриншоте указано: «Only Visuals are available». Это означает только показанное ограничение режима. Состав доступных визуальных функций и любые последствия для совместимости уточняйте по актуальной инструкции GLITCH.

Проблема появилась после обновления игры или Windows

Не откатывайте Windows, игру или драйверы без официальной инструкции. Зафиксируйте номер версии до и после обновления, приложите ошибку и обратитесь в поддержку за подтверждённым статусом совместимости.

HVCI снова включился или переключатель недоступен

Проверьте состояние после перезагрузки по инструкции для HVCI. Если Windows не даёт изменить параметр или возвращает его обратно, сохраните текст уведомления и версию ОС. На управляемом ПК настройку может задавать администратор. Передайте эти сведения поддержке, прежде чем менять дополнительные параметры.

Почему после перезагрузки снова работает FACEIT?

Штатное отключение драйвера FACEIT действует до перезагрузки. Отключайте его после всех необходимых перезапусков Windows либо используйте рекомендованное удаление Anti-Cheat. Порядок и проверка через CMD — в разделе FACEIT.

Нужно ли выключать VBS, Hyper-V или виртуализацию в BIOS?

Требование GLITCH к VBS пока не подтверждено. Сначала проверьте его состояние и сообщите поддержке. Не переносите инструкции для HVCI на Hyper-V или настройки BIOS: это разные параметры.

Как вернуть настройки для других игр?

Для возврата HVCI включите «Целостность памяти» на том же экране и перезагрузите ПК; при ошибке включения следуйте сообщению Windows. FACEIT после штатного отключения драйвера требует перезагрузки. Удалённые Anti-Cheat устанавливайте заново из официальных клиентов. Перед следующим запуском GLITCH повторно проверьте подготовку.

02 FACEIT Anti-Cheat — uninstall or disable

  1. Close the game and FACEIT Anti-Cheat.

Built-in driver control: FACEIT Support ↗

Disable through CMD and verify the result

This option applies only when the driver is registered as FACEIT and supports stopping. Its name and ability to stop may vary between versions.

  1. Search Start for cmd, choose Run as administrator, and accept the Windows prompt. Close FACEIT Anti-Cheat and the game.
  2. Run these two commands separately. They only read status and configuration: 
    sc.exe query FACEIT
sc.exe qc FACEIT
  3. Continue only if the service is a KERNEL_DRIVER and BINARY_PATH_NAME points to your installed FACEIT Anti-Cheat. Error 1060 means that this service name was not found; it does not prove Anti-Cheat is absent. Use uninstalling or Disable driver above.
  4. For the confirmed driver, run: 
    sc.exe stop FACEIT
sc.exe query FACEIT
  5. STATE should show STOPPED. If it says STOP_PENDING, wait and repeat only sc.exe query FACEIT. An error, access denial or RUNNING does not confirm success; use the built-in disable option or uninstall.

stop neither uninstalls Anti-Cheat nor changes its startup configuration. Check the driver again after a restart. Checking one service name does not confirm compatibility of the whole system.

03 HVCI — turn off Memory integrity

HVCI is the Memory integrity setting in Windows Security. Open it using the path for your OS:

Windows 11

Settings → Privacy & security → Windows Security → Device security → Core isolation details.

Windows 10

Settings → Update & Security → Windows Security → Device security → Core isolation details.

  1. Set Memory integrity → Off.
  2. Restart. Reopen this screen and confirm it still says Off.

Turning off HVCI reduces Windows protection. If the option is unavailable or managed by an organization, contact your PC administrator or GLITCH support.

Navigation and restart: Microsoft Support ↗

04 VBS — check separately

A requirement to disable VBS for GLITCH has not been confirmed. HVCI being off does not mean all of VBS is off. VBS, HVCI and Hyper-V are different concepts; check the specific setting.

  1. Press Win + R, enter msinfo32, then press Enter.
  2. In System Information, find Virtualization-based security.
  3. Copy the full value. If GLITCH fails to start, send it to support along with the HVCI state. This value alone does not establish the cause.

This check does not require disabling Hyper-V or CPU virtualization in BIOS/UEFI. Consult support before changing those settings for your configuration.

Troubleshooting

Loading or connection does not complete

Save the message text and time, confirm that your internet works in ordinary services, then try again later. If it persists, send the collected details through the official GLITCH support channel.

The menu is not visible or the key does not respond

Launch the GLITCH loader before RUST. With the game window active, press DEL (Delete). If the menu does not appear, send @cortez_1337 the product version, error text and the step where startup stopped.

The interface is too small, too large, or offset

First check the GLITCH interface options that are available to you, such as scale or font size. If that does not help, include screen resolution, Windows scaling, and a screenshot so support can investigate.

Behavior changed after adjusting a setting

Restore the last changed option to its previous value through the menu. Test one change at a time. If the issue persists, include a screenshot of the relevant section and describe the expected behavior.
